# hostorapms.com

The coming-soon page for **hostorapms.com**, served by GitHub Pages from the `main` branch.

- `index.html`: the page, the Hostora artwork centred on its green (#035537). `404.html` is the same page, so any
  address on the domain shows it.
- `hostora-coming-soon.png` / `.webp`: the logo and "Coming Soon", cut from the 1536×1024 artwork.
- `icon.png`: the browser tab icon (the ringed H). `og.jpg`: the picture shown when the link is shared.
- `CNAME`: the custom domain. GitHub Pages needs it; do not remove it.

DNS at GoDaddy: four `A` records for `@` (185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153)
and `www` as a CNAME to `abudauod.github.io`. The `test` record (the AWS load balancer) is not part of this site.
